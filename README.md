# Radio Energía Positiva

Sitio web de **Radio Energía Positiva**, hecho con React y Vite. Incluye reproductor en vivo, programación semanal, DJ’s, galería de videos de YouTube, chat en vivo con login de Google y redes sociales.

## Funciones

- Reproductor del stream en vivo y "Ahora en vivo" según la hora de Chile
- Programación semanal con el día actual resaltado
- Perfiles de los DJ’s con foto, programa y horario
- Galería de videos del canal de YouTube, con filtro por DJ y reproductor integrado
- Chat en vivo con inicio de sesión de Google (Firebase)
- Contacto, redes sociales y enlace a la app móvil
- Modo claro y oscuro

## Tecnologías

React 18 · Vite 5 · Firebase (Authentication y Firestore) · YouTube Data API v3

## Requisitos

- Node.js 18 o superior
- Una cuenta de Firebase (el plan gratuito basta)
- Una API key de YouTube Data API v3 (opcional, para la galería)
